# WhatsApp message templates for Ahadi

Generated by `npm run wa:templates` from `src/lib/waTemplates.ts`. Do not edit by hand.

Create each template in **WhatsApp Manager → Message templates → Create template**. The **name**, **language** and **body** must match exactly (the app sends the variables in the order shown). Add the sample values when Meta asks for examples.

## 1. Login code (category: Authentication)

- Name: your choice, e.g. `ahadi_login_code`. Put it in `WHATSAPP_OTP_TEMPLATE`.
- Languages: English (`en`) and Swahili (`sw`).
- Code delivery: **Copy code** button. Meta writes the text for authentication templates; you only choose the options.

## 3. Webhook (delivery reports)

In your Meta app → WhatsApp → Configuration:

- Callback URL: `https://<your-domain>/api/webhooks/whatsapp`
- Verify token: any long random text; put the same value in `WHATSAPP_VERIFY_TOKEN`.
- Subscribe to the **messages** field.
- Put the app secret (App settings → Basic) in `WHATSAPP_APP_SECRET`.
